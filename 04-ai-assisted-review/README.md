# AI-Assisted Review Workflow

This folder documents how I use AI-assisted tools to support my cybersecurity learning process.

The purpose of this workflow is not to replace learning or complete assessments. The goal is to improve review, repetition, structure, recall, and documentation.

## Tools Used

- NotebookLM / Gemini Notebook
- ChatGPT / Atlas
- OneDrive
- Start.me
- Markdown notes
- Personal study files

## How I Use AI-Assisted Review

I use AI-assisted tools to:

1. Review concepts after studying them
2. Organize personal notes
3. Create summaries from my own learning materials
4. Build glossaries and study references
5. Improve recall through repetition
6. Transform private notes into public-safe documentation
7. Prepare structured portfolio materials

## Academic Integrity

AI-assisted tools are used as learning support, not as a substitute for independent work.

I do not use AI to complete graded assessments, answer quizzes, or submit work that is not my own.

Course materials, assessment questions, answer keys, restricted content, and private scenarios are not published in this repository.

## Workflow

My current workflow is:

1. Study the source material
2. Take personal notes
3. Review the concepts with AI-assisted tools
4. Rewrite the material in my own words
5. Remove restricted or private details
6. Create a public-safe summary or documentation entry
7. Store the final version in GitHub when appropriate

## Purpose

This workflow helps me learn more actively, document my progress, and build a responsible cybersecurity portfolio over time.
