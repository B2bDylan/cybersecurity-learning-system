The goal is to organize my studies, notes, labs, review methods, and practical outputs in a clear and structured way.

## Learning Path

My current learning path includes:

- Google Cybersecurity Professional Certificate

## Study Method

My study method is based on:

1. Study the topic
2. Take notes
3. Review key concepts
4. Create summaries
5. Practice in labs when possible
6. Document the learning process
7. Transform public-safe knowledge into awareness content

## AI-Assisted Review Workflow

I use AI-assisted tools as part of my study system, not to replace learning, but to improve review, repetition, structure, and recall.

Tools used in the workflow:

- NotebookLM / Gemini Notebook

- OneDrive
- Start.me
- Markdown notes
