# Methodology

This folder documents my personal learning methodology as I transition into cybersecurity.

The goal is to show how I organize study materials, review concepts, take notes, practice in labs, and transform learning into structured documentation.

## Learning Workflow

My current workflow is based on:

1. Study the topic
2. Take personal notes
3. Review key concepts
4. Create summaries
5. Practice in authorized labs when possible
6. Document the learning process
7. Transform public-safe knowledge into portfolio entries or awareness content

## Tools Used

- Google Cybersecurity Professional Certificate
- TryHackMe
- NotebookLM / Gemini Notebook
- ChatGPT / Atlas
- OneDrive
- Start.me
- GitHub
- Markdown notes

## Purpose

This methodology helps me build consistency, improve recall, organize my learning, and create evidence of my cybersecurity development over time.
